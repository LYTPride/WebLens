# 登录、用户与作用域权限

WebLens 需要登录后才能进入操作页面。当前版本提供两层权限模型：`admin/user` 保存平台身份，`isRoot` 区分唯一根管理员与受委派的平台管理员，`viewer/operator` 决定普通用户在具体作用域内能做什么。

## 首次初始化

发布包默认使用 `data/weblens.db` 保存用户、平台配置和授权数据。发布升级时不要覆盖 `data/` 目录。

首次解压后先执行：

```bash
./scripts/init.sh
```

初始化脚本会创建唯一的根管理员 `admin` 并要求设置密码，密码输入不回显且需要二次确认。`admin` 的 root 标记由数据库迁移、唯一索引和保护触发器共同维护，不能通过 Web/API 改名、禁用、删除或降级。未初始化时直接执行 `scripts/weblens-start.sh` 或 `scripts/weblens-restart.sh` 会提示先运行初始化脚本。

旧版本升级时，初始化会把原 `config/kubeconfig-dir.override` 和 `config/cluster-combos.json` 中的平台配置迁移到 SQLite；旧文件保留，不作为新版本的主要配置来源。

## 登录与会话

- 登录页使用固定深色双栏视觉，左侧为 WebLens 品牌与低刺激呼吸式视频背景，右侧为账号密码表单；登录页不提供深浅主题切换。
- 密码默认以圆点隐藏，可用小眼睛图标切换显示；用户名、密码和首次改密输入框使用高对比光标。
- 用户名加数据库中的密码哈希不能登录，必须输入原始密码。
- 会话保存在服务端，浏览器使用 HttpOnly Cookie。
- 根管理员、平台管理员和普通用户默认 20 分钟无操作超时。
- 超时前 30 秒会弹出倒计时提示，点击继续使用会续期；倒计时结束会直接登出。
- Logs、Shell 和 Watch 等长连接不会刷新空闲时间；正在编辑但未保存的 YAML 超时后不会自动保存。
- 用户被禁用、密码被重置或授权被撤销后，HTTP 请求会立即按新状态校验；活动 Watch / Shell 最迟在下一轮约 5 秒的服务端复核中断开。

## 平台身份与管理边界

平台身份分为三类：

- 根管理员：固定用户名 `admin`，`role=admin` 且 `isRoot=true`。它是唯一的本机应急账号，可访问全部 Kubernetes API 代理路径，包括未加入平台作用域的命名空间和隐藏的集群级资源。
- 平台管理员：`role=admin` 且 `isRoot=false`。可维护平台配置、用户、作用域分组、授权和审计；在所有“已添加作用域”中按运维角色工作，但不能借平台管理员身份访问未添加的命名空间或集群级 Nodes。
- 普通用户：`role=user`。只能看到明确授予的作用域，并按观察者或运维角色工作。

根管理员和平台管理员都可以：

- 创建平台管理员或普通用户；创建平台管理员前页面会再次确认高权限身份。
- 为普通用户配置作用域组授权或单独作用域授权。
- 禁用、启用、重置或删除其他平台管理员和普通用户。
- 维护 kubeconfig 目录、已添加作用域和作用域分组。
- 查看权限管理、密码变更、资源操作、Shell 和权限拒绝等审计记录。
- 修改自己的密码。

管理边界如下：

- 任何管理员都不能通过用户管理接口禁用、删除或重置根管理员 `admin`。
- 管理员不能通过用户管理接口禁用、删除或重置当前登录账号；本人密码只能从个人设置修改。
- 平台管理员之间可以相互管理，根管理员也可以管理所有平台管理员。
- 删除用户前必须先禁用；禁用和重置密码都会撤销该用户的全部会话。
- 数据库触发器仍会阻止对 root 身份字段的直接更新或删除，避免只依赖页面保护。

## 一次性临时密码

创建用户和管理员重置密码时，后端都会生成独立的密码学随机临时密码，不再使用共享固定默认密码。临时密码只在本次 API 响应和页面提示中出现，数据库只保存 bcrypt 哈希；关闭提示后不能重新查询原文，只能再次重置。

收到临时密码的用户可以登录，但必须先设置永久密码，改密完成前不能进入其他功能。重置密码时，该用户的既有会话立即失效，活动 Watch / Shell 会在服务端下一轮复核时关闭。

## 根管理员密码遗失时的本机恢复

WebLens 不提供网页或远程 API 来重置 root 密码。具备 WebLens 主机和部署目录访问权限的运维人员，在交互式终端执行：

```bash
cd <WebLens 部署目录>
./scripts/reset-admin-password.sh
```

包装脚本会按以下顺序执行：

1. 加载 `config/weblens.env`，因此会使用与服务端相同的 `WEBLENS_DB_PATH`。
2. 检查服务端二进制、交互式终端和数据库初始化状态。
3. 展示影响范围，并要求完整输入 `RESET admin`，避免误操作。
4. 以隐藏输入方式读取并二次确认临时密码；密码不会出现在命令行参数或 shell history 中。
5. 通过标准输入调用 `weblens-server reset-admin-password`。后端只按唯一的 `is_root=1` 记录定位账号，不接受用户 ID 或用户名参数，因此不能被改用于重置其他管理员。
6. 在单个数据库事务中更新 bcrypt 哈希、设置强制改密、撤销 root 全部会话，并写入 `root.password.recovery` 审计记录；任一步失败都会整体回滚。

服务运行期间可以直接执行恢复脚本，不需要先停机。成功后：

- 原 `admin` 密码立即失效。
- `admin` 的全部浏览器会话被撤销，活动 Watch / Shell 最迟约 5 秒关闭。
- 新密码只是临时密码；`admin` 下次登录必须立即设置永久密码。
- 审计记录显示操作者为 `system:local-recovery`、目标为 `platform-user/admin`，并记录撤销的会话数量，但不记录密码。
- 平台管理员和普通用户的密码、会话及授权不受影响。

平台管理员不能在 Web 控制台中执行此恢复。如果同时失去主机访问权，需要先通过服务器或容器平台的基础设施流程恢复主机权限；不要直接编辑 SQLite 密码哈希或删除数据库。

## 普通用户能力

普通用户可执行：

- 首次使用一次性临时密码登录后强制修改密码，修改完成前不能进入操作页面；首次改密页只要求输入新密码和确认新密码，不再要求重复输入临时密码。
- 修改自己的密码。
- 选择、应用和查看被平台管理员授权的作用域。
- 观察者可查看资源、Describe、Logs、文件和只读 YAML，不能执行资源写操作、Shell 或文件写入。
- 运维可在观察者能力基础上执行编辑、删除、扩缩容、重启、Shell 和文件写入。
- 登出系统。

如果普通用户没有任何授权作用域，登录后仍可进入应用，但资源区显示“暂无授权作用域，请联系管理员”，页面只保留修改密码和登出能力。

## 作用域模型

作用域是一个明确的 `集群 + 单一 namespace`，等价于：

```bash
kubectl --kubeconfig <config_file> -n <namespace>
```

系统不会默认选择或应用作用域。登录后用户必须自行选择作用域并点击“应用”，才会加载对应资源。

## 角色授权与作用域分组

作用域分组用于表达团队、项目或环境边界，角色用于表达用户能做什么，两者相互独立：

- 一个用户可以对多个分组分别获得观察者或运维角色。
- 未加入分组的作用域可以直接授权给用户。
- 分组授权和直接授权重叠时取较高角色，例如分组为观察者、单独作用域为运维时，该作用域最终为运维。
- 旧版已有作用域授权升级后自动作为运维授权保留。
- 当前作用域角色会显示在 Console 顶部；观察者打开 YAML 时进入只读模式。

WebLens 角色不会绕过 Kubernetes RBAC。即使 WebLens 授予运维角色，目标集群账号仍需拥有相应 Kubernetes 权限。

## 权限调整生效

普通用户在线时，作用域列表和角色会随登录状态刷新。作用域被撤销后，页面停止继续使用该作用域；Shell 权限被撤销或降级后，活动会话会在下一次权限复核时关闭。

根管理员或平台管理员可从右上角盾牌菜单直接进入“用户管理”“角色授权”“作用域分组”“审计记录”，四个入口与权限配置弹窗的四个页签一一对应。

- 用户管理支持按用户名即时过滤；创建或重置密码后，可使用提示区的“复制临时密码”，在浏览器限制 Clipboard API 时会自动使用兼容复制方式。
- 角色授权先在左侧搜索并选择用户，右侧分别维护“作用域组授权”和“单独作用域授权”；两个列表各自提供搜索框、结果计数和独立滚动区，修改统一通过“保存授权”提交。
- 作用域分组使用“分组列表 + 分组详情”布局；左侧可搜索或新建分组，右侧维护名称、说明和分组内作用域，作用域列表也可按集群、namespace 或别名过滤。
- 审计记录用于按用户、操作和结果追踪权限变更与受控操作；“日志”列仅在资源操作包含用户填写的日志时显示“查看”，其他记录显示“—”。审计记录不显示来源 IP。

具备当前作用域写权限的用户（包括根管理员和平台管理员）执行删除、重启、扩缩容、YAML/配置保存或已有批量高危操作时，必须先填写本次操作的背景、原因或目的。操作日志最多 500 个字符，不能为空；填写后仍需在原资源确认窗口再次确认。取消任一弹窗都不会执行操作。

如果绕过页面直接调用资源写接口且未携带操作日志，后端会拒绝请求，因此该要求不只是前端提示。

列表搜索均为当前页面内的即时过滤，不会修改或提交授权数据；清空搜索框即可恢复完整列表。

# 登录、用户与作用域权限

WebLens 需要登录后才能进入操作页面。当前版本提供轻量用户模型：`admin` 管理平台配置、用户和作用域授权；普通用户只能看到并操作被授权的作用域。

## 首次初始化

发布包默认使用 `data/weblens.db` 保存用户、平台配置和授权数据。发布升级时不要覆盖 `data/` 目录。

首次解压后先执行：

```bash
./scripts/init.sh
```

初始化脚本会要求设置 `admin` 密码，密码输入不回显，并需要二次确认。未初始化时直接执行 `scripts/weblens-start.sh` 或 `scripts/weblens-restart.sh` 会提示先运行初始化脚本。

旧版本升级时，初始化会把原 `config/kubeconfig-dir.override` 和 `config/cluster-combos.json` 中的平台配置迁移到 SQLite；旧文件保留，不作为新版本的主要配置来源。

## 登录与会话

- 登录页使用固定深色双栏视觉，左侧为 WebLens 品牌与低刺激呼吸式视频背景，右侧为账号密码表单；登录页不提供深浅主题切换。
- 密码默认以圆点隐藏，可用小眼睛图标切换显示；用户名、密码和首次改密输入框使用高对比光标。
- 用户名加数据库中的密码哈希不能登录，必须输入原始密码。
- 会话保存在服务端，浏览器使用 HttpOnly Cookie。
- admin 和普通用户默认 20 分钟无操作超时。
- 超时前 30 秒会弹出倒计时提示，点击继续使用会续期；倒计时结束会直接登出。
- Logs、Shell 和 Watch 等长连接不会刷新空闲时间；正在编辑但未保存的 YAML 超时后不会自动保存。

## admin 能力

admin 可执行：

- 维护平台配置，包括 kubeconfig 目录和已添加作用域。
- 创建普通用户，创建时只填写用户名，默认密码为 `WebLens@2026`；创建成功提示会展示默认密码并提供复制按钮。
- 重置普通用户密码，重置后密码回到 `WebLens@2026`，该用户下次登录必须先修改密码。
- 为普通用户授权已添加作用域；授权列表支持按 kubeconfig、命名空间或别名搜索。
- 禁用或启用普通用户；禁用后在线用户会在心跳检查时登出。
- 删除已禁用的普通用户；未禁用时删除会提示先禁用。
- 修改自己的密码。

admin 不能禁用或删除自己。

## 普通用户能力

普通用户可执行：

- 首次使用默认密码登录后强制修改密码，修改完成前不能进入操作页面；首次改密页只要求输入新密码和确认新密码，不再要求重复输入当前默认密码。
- 修改自己的密码。
- 选择、应用和查看被 admin 授权的作用域。
- 在授权作用域内执行当前版本已有的资源操作。
- 登出系统。

如果普通用户没有任何授权作用域，登录后仍可进入应用，但资源区显示“暂无授权作用域，请联系管理员”，页面只保留修改密码和登出能力。

## 作用域模型

作用域是一个明确的 `集群 + 单一 namespace`，等价于：

```bash
kubectl --kubeconfig <config_file> -n <namespace>
```

系统不会默认选择或应用作用域。登录后用户必须自行选择作用域并点击“应用”，才会加载对应资源。
